# Starting To Learn Again

---
**TLDR:**  
I want to get back to having fun while programming and learning so I decide to learn C, Zig in order to write custom code for an E-INK display

---

In recent times and especially the last couple of months, I have felt a bit overwhelmed and saddened by the impact AI has had.

It has robbed me of the little joys I had, fixing a difficult bug, writing a new complex feature that works, or just solving issues while figuring things out.  

Now I'm not delusional, I know that things in the professional world won't go back to the way they were before AI.   
However, I already notice that leaning too much on the machine atrophies my skills in every area that I lean on it, and most importantly, it also rips out the fun of the aforementioned tasks.  

So since the job portion of the reality won't change, I have to change what I can, which is my free time.

<br>
Some people have shown me I'm not alone in this feeling and ambition to get fun and learning back into programming.

## What Is The Goal?

The end goal is to buy a TRMNL E-INK display, and write custom plugins.
Creating a `server` that gathers inputs as well as a `renderer` for the display

![TRMNL E-INK Display Image](https://shop.trmnl.com/cdn/shop/files/section2-1.jpg?v=1753901574&width=1600)

That is it. That still leaves a lot of work to be done, learning C and Zig to enable the writing of the renderer.  

## How Will I Try To Achieve This?

There are a couple of steps to it, but overall it is quite simple.

- [ ] Learn C via [Beej's Guide to C Programming](https://beej.us/guide/bgc/) (Trying to learn C first to understand Zig better & deeper)   
- [ ] Learn Zig via [ziglings](https://codeberg.org/ziglings/exercises/#ziglings)
- [ ] Buy an E-INK Display 
- [ ] Write the Server in Go 
- [ ] Write the Renderer in Zig

Seems simple, just 5 steps in total, one of which takes almost no effort.  
It is simple, but that doesn't mean it's not hard. 

###  What Are Some Rules I Am Setting For Myself?
*There are only a couple rules so far (I might add more later, look out for `edit: `).*

- *AI will not write a single line of code in the project*
- *Only use AI to debug if I can't find a solution in the documentation / no-ai search*

Therefore this project will be an `AI:R` rating on the `0RWX` scale from *NoBoilerplate's* video.
